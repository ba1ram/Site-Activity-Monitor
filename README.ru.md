# Activity Monitor

[🇬🇧 English](README.md) · [🇷🇺 Русский](README.ru.md)

Небольшой браузерный инструмент для мониторинга и анализа активности текущей вкладки.

**Онлайн-версия:** [ba1ram.github.io/Site-Activity-Monitor](https://ba1ram.github.io/Site-Activity-Monitor/)

## Возможности

* Мониторинг активности и состояния текущей вкладки
* Отслеживание браузерных событий, включая:

  * события мыши и указателя
  * нажатия клавиш
  * копирование, вырезание и вставку
  * прокрутку и колесо мыши
  * изменение фокуса и видимости страницы
  * события ввода и форм
  * Drag & Drop
  * Touch-события
  * fullscreen и изменение размера окна
  * состояние online / offline
  * события жизненного цикла страницы
* Журнал событий со временем до миллисекунд
* Фильтрация событий
* Статистика времени мониторинга и активного времени
* Информация о текущем состоянии браузера и вкладки
* Экспорт собранных событий в JSON
* Интерфейс на русском и английском языках
* Не требует установки и зависимостей

## Как использовать

1. Откройте [онлайн-версию](https://ba1ram.github.io/Site-Activity-Monitor/).
2. Нажмите **Старт**.
3. Выполняйте действия в текущей вкладке.
4. Просматривайте собранные события в журнале.
5. Используйте **Фильтр**, чтобы скрыть ненужные события.
6. При необходимости экспортируйте собранные данные в JSON.

Фильтр событий работает по принципу **чёрного списка**: события отображаются по умолчанию, а скрываются только явно выбранные типы событий.

## Конфиденциальность

Монитор работает полностью в браузере.

Собранные события не отправляются на сервер. Содержимое буфера обмена и значения полей форм монитором не сохраняются.

Инструмент предназначен для диагностики, тестирования и экспериментов с браузерными событиями.

## Ограничения

Это небольшой браузерный диагностический инструмент, а не полноценная система записи активности или античит.

Браузерные API имеют собственные ограничения, поэтому некоторые события или данные могут работать по-разному в зависимости от браузера, операционной системы и устройства.

## Лицензия

Проект предоставляется как есть для личного использования, экспериментов и обучения.
